# 智慧氣象查詢系統（Smart Weather Query System）

一個結合**中央氣象署開放資料 API**、**情境智慧提醒**與**多城市視覺化對比**的互動式網頁查詢系統，透過 GitHub Pages 託管提供即時線上瀏覽。

🔗 **線上展示網址**：[https://a65b68-debug.github.io/githubmyself/](https://a65b68-debug.github.io/githubmyself/)

---

## 核心功能亮點

* **全台 22 縣市即時觀測查詢**：支援臺灣本島與離島共 22 個縣市切換，即時串接官方測站數據（氣溫、相對濕度、風速、天氣現象、測站名稱與觀測時間）。
* **智慧生活與異常情境提醒**：依據即時氣溫、相對濕度（如高於 75% 悶濕提醒）與風速條件，自動生成日常外出與防曬、保暖或防風建議。
* **多城市氣溫與濕度對比圖表**：同步呈現北、中、南、東代表城市（臺北市、臺中市、高雄市、花蓮縣）的氣溫與濕度視覺化長條對比。
* **雙模式容錯與金鑰安全設計**：支援使用者於前端畫面輸入中央氣象署 API 授權碼取得即時資料；未輸入授權碼或網路異常時，自動切換為內建示範資料以確保畫面穩定運作，且不在公開程式碼中暴露個人金鑰。

---

## 系統運作與資料流架構

1. **資料擷取與標準化**：向中央氣象署開放資料平臺（資料集代碼 `O-A0003-001`）請求 JSON 格式觀測資料，統一「臺／台」縣市名稱規則並過濾異常缺值。
2. **規則引擎判斷**：將解析後的氣象數值傳入情境判斷函式，產出對應的體感與生活提醒文案。
3. **前端介面與視覺化渲染**：使用原生 HTML5、CSS3 與 JavaScript（ES6+ Fetch API）動態更新數據卡片與對比長條圖。

## 使用方式

1. 開啟網頁：[https://a65b68-debug.github.io/githubmyself/](https://a65b68-debug.github.io/githubmyself/)
2. 於左上角下拉選單選擇欲查詢的縣市。
3. 若需取得即時觀測數據，可於輸入框貼上[中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/)申請之 API 授權碼後點擊「查詢氣象」；留空則可直接體驗內建示範資料。

## 資料來源與技術棧

* **資料來源**：交通部中央氣象署開放資料平臺（自動氣象站／局屬氣象站即時觀測資料 `O-A0003-001`）
* **前端技術**：HTML5、CSS3（RWD 響應式卡片與圖表排版）、JavaScript（Fetch API 非同步資料解析）
* **部署平臺**：GitHub Pages
